Background Error Covariance in 3D-Var

Interactive demo: How B shapes the analysis increment

Cost Function (3D-Var)

J(x) = ½(x - xb)T B-1 (x - xb) + ½(y - Hx)T R-1 (y - Hx)
B-1 penalizes departure from background  |  R-1 penalizes departure from observations
The analysis minimizes J — balancing trust in forecast vs. observations.

B Matrix Decomposition (SABER Block Chain)

B = T · V · K · Σ · C · ΣT · KT · VT · TT
C = correlation (central block: NICAS, diffusion, spectral)   Σ = std dev   K = balance
V = variable change (ψ,χ → u,v)   T = interpolation
Click on the heatmaps to place observations. The increment shows how information spreads from obs to the analysis.
